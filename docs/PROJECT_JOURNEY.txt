5. MCP SERVER — THE FOUNDATION
--------------------------------
  Built an MCP server with 5 intent-based tools:

    capture_task   → Create a new task from natural language
    review_task    → List, search, and filter tasks
    modify_task    → Update existing task fields
    resolve_task   → Mark a task as completed
    remove_task    → Delete a task permanently

  Tech: Python 3.12, FastMCP, Streamable HTTP transport, InMemoryTaskStore
  Docs: spec/mcp/ — transport, tools, implementation plan, testing, roadmap


6. DOCKER + CI/CD — AUTOMATION
--------------------------------

  - Added non-root user for security
  - Added HEALTHCHECK for container monitoring
  - Set up GitHub Container Registry (ghcr.io)
  - Configured GitHub Actions to auto-build on every push
  - Image: ghcr.io/asifalishaikh/task-manager-agent/task-manager-mcp


7. OPENAI AGENTS SDK — RESEARCH
---------------------------------
  Studied the SDK documentation to understand two agent types:

  AGENT (Simple):
    - Core building block with instructions, tools, MCP, handoffs, guardrails
    - Works with any LLM via LiteLLM
  
  SANDBOXAGENT:
    - Extends Agent with workspace isolation
    - Adds Filesystem, Shell, Skills, Memory, Compaction capabilities
    - Uses DockerSandboxClient for container-level isolation
    - Bridges to Kubernetes deployment

  DECISION: Use Simple Agent now, SandboxAgent for K8s later
  DOCS: docs/adrs/agent-decision.md, spec/agents/sandbox-agent-spec.md


8. TESTING — VERIFY EVERYTHING
--------------------------------
  Two API keys were used during testing:
    - Gemini API Key: Used by the agent to call MCP tools and respond to prompts
    - OpenAI API Key: Used only for tracing (optional, no cost impact)

  Test 1: Hello Gemini
    - Simple Agent with Gemini 3.1 Flash-Lite via LiteLLM
    - Verified: Gemini responds correctly ✅

  Test 2: Simple Agent + MCP
    - Agent runs directly on local machine
    - Connects to MCP server running in Docker
    - Verified: List tools, create task, review task all work ✅

  Test 3: SandboxAgent + Docker + MCP
    - Agent runs inside Docker container via DockerSandboxClient
    - MCP tools work through Gemini
    - Verified: Docker container starts, MCP tools work, task created ✅

  LIMITATION FOUND:
    Sandbox built-in capabilities (Filesystem, Shell) require OpenAI's
    Responses API — not available with Gemini via LiteLLM (uses
    ChatCompletions). MCP tools work with both.
